# analisis-cobertura-mediatica

Analizar la cobertura de prensa y redes sociales sobre una persona o caso para asesoría en PR y comunicación de crisis: extraer notas (Excel/nexnews), scrapear textos y perfiles con agent-browser, clasificar tono y relevancia, consolidar cuantitativo y cualitativo y redactar un informe Word con cada afirmación citada por enlace. Usar cuando se pida medir cómo los medios y las RRSS han cubierto a un sujeto, imputado, empresa o caso.

## Contenido

- [SKILL.md](SKILL.md): instrucciones principales de la skill.
- Carpetas y archivos de apoyo: referencias, scripts, datos y recursos que necesita la skill.

## Instalar en Codex

Copia esta carpeta completa en:

- Windows: %USERPROFILE%\.codex\skills\analisis-cobertura-mediatica\
- macOS/Linux: ~/.codex/skills/analisis-cobertura-mediatica/

Conserva la estructura de carpetas, porque SKILL.md puede enlazar a recursos incluidos.
